# Lab: Funciones en JavaScript — Declarativas, Flecha y Callbacks

## 📖 Descripción del Laboratorio

Profundización en el diseño y uso de funciones en JavaScript: declaraciones tradicionales, expresiones, funciones flecha (arrow functions) y callbacks.

---

## 🎯 Objetivos y Requisitos Técnicos

- [x] Declaración de funciones y retorno de valores
- [x] Funciones flecha (`() => {}`) y contexto léxico
- [x] Parámetros por defecto y parámetros rest (`...args`)
- [x] Funciones de orden superior (Higher Order Functions)

---

## 🛠️ Tecnologías y Herramientas

- **JavaScript ES6+**
- **Manipulación del DOM**
- **HTML5 & CSS3**
- **Git & GitHub**
